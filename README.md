# Introducción al Modelado Continuo · clases interactivas

Slides interactivas de la práctica de Introducción al Modelado Continuo (Lic. en Ciencia de Datos, FCEN-UBA, 2C 2026).

**Sitio:** https://agustinbrusco.github.io/imc-animaciones/

Cada clase es una página HTML autocontenida: funciona también sin internet si se descarga el repo y se abre
`index.html` en el navegador.

Este repo se genera automáticamente desde el material de la materia: no se edita a mano.

## Créditos

- Piano: [University of Iowa Musical Instrument Samples](https://theremin.music.uiowa.edu/MIS.html).
- Ballena jorobada: grabación de Glacier Bay National Park (NPS), dominio público.
- Fuente Computer Modern Unicode (SIL Open Font License, ver `vendor/cmu/OFL.txt`).
- Fórmulas con [MathJax](https://www.mathjax.org/) (Apache 2.0, ver `vendor/mathjax/LICENSE`).
